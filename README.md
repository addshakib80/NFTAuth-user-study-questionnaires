# User Study Questionnaires

Usability and user experience evaluation instruments used in the paper:

**A Secure Authentication Mechanism for Federated Metaverses Using Non-Fungible Tokens (NFTs)**
Mohammed Shakib Hossain, Khawaja Ehsun Ul Hawak, Mutasin Jawad, Md Yeasin Ali, Sagar Karmoker, Masum Alam Nahid, Hossain Shahriar, Md Sadek Ferdous
*IEEE Blockchain 2026 (IEEE Cybermatics Congress 2026)*

---

## Overview

This repository contains the questionnaire instruments used to evaluate the usability and user experience of the proposed NFT-based authentication system in a VR-enabled metaverse. A usability evaluation was conducted with 25 participants recruited via convenience sampling, combining the System Usability Scale (SUS) with a custom 9-item user experience (UX) survey. Full study design, methodology, and results are reported in Section V of the paper.

Only the questionnaire instruments are shared here. Raw, individual-level participant responses are not published, in line with the consent scope of the study; the paper reports aggregated results (score distributions, means, and statistical comparisons).

## Contents

| File | Description |
|---|---|
| `SUS_Questionnaire.pdf` | Standard 10-item System Usability Scale (SUS), scored 0–100 [1]. |
| `UX_Feedback_Questionnaire.pdf` | Custom 9-item UX survey assessing learnability, efficiency, satisfaction, and system integration. |

## Instrument Design

- Both instruments use a 5-point Likert scale (1 = Strongly Disagree, 5 = Strongly Agree).
- The custom UX survey is grounded in ISO 9241-11, Nielsen's usability heuristics, and the Technology Acceptance Model (TAM).
- Participants completed the NFT-based authentication flow in a VR-enabled metaverse after a brief system demonstration, then completed both questionnaires.

## Results Summary

The system achieved a mean SUS score of 69.4 ± 18.7 (N = 25), within the "good" usability range, and a mean custom UX score of 4.34/5. Full quantitative results, including per-item breakdowns and statistical analysis, are reported in the paper.
